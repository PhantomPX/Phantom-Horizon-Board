# Phantom-Horizon-Board

An overpowered dev board with dual MCU, ESP32 for wireless connection and STM32 for GPIOs and ADC pins.

It's a great dev board for testing & prototyping for projects using motors.
I'll be using the board to prototype my upcoming project [Phantom Strata](https://github.com/PhantomPX/Phantom-Horizon-Board) CNC machine
